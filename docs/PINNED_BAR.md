# 首页置顶栏与外观设置

本功能实现于 Pinning 插件，不修改 Core 或数据库结构。沿用已有的置顶操作、权限、排序、计时和普通动态流成员关系。

- 默认是单行横栏，展开后保留横栏并显示紧凑列表。背景图、正文图片和互动工具栏不进入摘要列表。

## 数据与交互

`GET /isbf/pinning/topics.json` 通过原生 `TopicQuery` 和 `TopicListSerializer` 获取当前访问者可见的全部有效首页置顶。保留原有首页过滤、置顶排序与个人清除规则；排除过期、删除、隐藏、私信、不可访问分类和分类说明主题。

接口返回原生摘要、真实作者和经过权限过滤的默认帖子 ID。客户端按作者用户 ID 去重头像，窄屏减少头像并显示 `+N`。默认标题无效时使用现有顺序第一条。无有效帖子时整栏隐藏，普通动态流仍按原规则显示原帖。

摘要转换为纯文本并由 Glimmer 转义输出。列表使用原生帖子链接。展开按钮支持键盘、`aria-expanded`、`aria-controls`，折叠内容不可获得焦点。动画遵守减少动态效果偏好。

服务在置顶操作事件、窗口重新获得焦点、到期时间和至多 30 秒的周期刷新数据；共享请求避免重复加载，并在离开页面时释放监听和计时器。

## 开发者设置与持久化

入口：管理员后台「外观 → 界面与布局」（`/admin/config/interface`）页的「置顶栏外观」卡片。使用原生 `AdminConfigAreaCard`、FormKit、DButton、SiteSettingUpload 和批量设置接口，不另建权限体系或上传存储。

| 设置 | 保存位置 | 范围 |
| --- | --- | --- |
| 填充、边框、粗细、透明度、水平/垂直位置、适配与溢出 | `isbf_pinning_bar_appearance` JSON | light/dark 独立 |
| 默认展示帖子 | `isbf_pinning_bar_default_topic_id` | 非公开客户端设置；接口按可见性解析 |
| 日夜 × 桌面/移动背景图 | `isbf_pinning_bar_{light,dark}_{desktop,mobile}_image` | 原生 Upload 设置，共四项 |
| 显示背景可见范围 | 浏览器本地 `isbf-pinning-preview-guides` | 只用于开发者预览，不进入公开配置 |

颜色为八位 RGBA 十六进制，支持完全透明；边框 0–4 px、步进 0.5；图片透明度 0–1；水平位置 0–100%；垂直偏移 −500–500 px。前后端均校验，服务端拒绝多余键、非法数值和 CSS 注入。

保存沿用原生批量设置 API，保存中禁用编辑字段。切换日夜模式不丢失未保存的另一套参数；恢复默认只重置当前模式及其两张图片。移动图片缺失时，只回退到同一日夜模式的桌面图片。

页面显示上传、替换、清除、原图查看及图片制作建议。仅底层 `User.admin` 为真的开发者可以写设置或提交这些图片；普通成员和版主的直接请求同样由服务端拦截。

图片限制：PNG、WebP、JPEG；不超过 5 MiB、单边不超过 8192 px、总像素不超过 1600 万。上传前读取实际图片类型和尺寸，原生处理流程继续负责文件存储、解码和缩放。设置验证另行拒绝私密 Upload、不匹配的格式或超限文件。

## 装饰图层与定位

图层由低到高为填充、装饰图片、交互内容、边框。装饰容器和图片均不接收指针事件，无负 z-index；普通动态列表处于装饰层上方。

图片按固定参考区域等比缩放：桌面参考比例 1600:400，移动参考比例 900:320。完整显示选择较小缩放比，覆盖选择较大缩放比。水平位置分配剩余宽度；垂直位置锚定横栏中心并加上偏移。展开只改变列表高度，不改变图片缩放或锚点。

`ResizeObserver` 读取实际布局尺寸，图片加载、容器尺寸或日夜模式变化都会重新计算。使用布局像素计算内部坐标，避免父级缩放导致图片重复缩放。

允许延伸时，绝对定位的装饰窗口扩展到置顶框上方和下方；下方窗口以实际动态流末尾为界，防止超长图片额外增加页面滚动空间。窗口内部裁切图片，不改变原文件，也不增加横栏布局高度。限制在框内时，窗口收回置顶框并使用相同圆角裁切。

## 可见范围辅助线

首页与编辑器复用同一个组件。预览读取图片自然宽高、预览宽度、横栏及展开列表实际高度、缩放方式、水平定位和垂直偏移，反算图片原坐标中的交集。

预览同时显示当前页面效果和完整原图。实线标记置顶框的实际边界，上下延伸区使用轻量条纹和标签；PNG/WebP 下方显示透明棋盘格。切换设备、折叠状态或参数时重新计算。辅助标记仅存在于后台预览组件中，不写入图片，也不进入首页组件。

## 文件分工

- `plugin.rb`、`lib/isbf_pinning/bar_*.rb`：只读列表、序列化、设置及图片校验、服务端权限。
- `config/settings.yml`、`config/locales/`：原生设置及中英文文案。
- `assets/javascripts/discourse/components/`：首页入口和公共置顶组件。
- `assets/javascripts/discourse/lib/pinned-bar.js`：参数解析、作者去重、标题回退、摘要与几何计算。
- `assets/javascripts/discourse/services/isbf-pinned-bar.js`：共享加载、更新和到期处理。
- `admin/assets/javascripts/discourse/`：原有开发者设置扩展、FormKit 控件及实时预览。
- `assets/stylesheets/`：公共栏及后台编辑器样式。
- `spec/`、`test/javascripts/`：权限、数据、设置、上传、控件绑定、摘要及背景预览测试。
